Praktikum Pemrograman Web

Mata kuliah praktikum ini mempelajari dasar-dasar pengembangan web secara front-end maupun back-end sederhana. Mahasiswa akan diajarkan cara membuat halaman web yang interaktif, responsif, dan terstruktur dengan baik.

Materi yang Dipelajari:
  • Pengenalan HTML5 & Struktur Dokumen Web
  • Styling menggunakan CSS3 & Framework Bootstrap
  • Interaktivitas dasar dengan JavaScript
  • Pembuatan Layout Responsif (Responsive Web Design)
